Study materials for character identification on HSK 2, Chapters 7–12.

  New Words tables (source material, HSK1–3).
- [HSK2-CH7-12-CHARACTERS.md](HSK2-CH7-12-CHARACTERS.md) — printable
  character-by-character study sheet for the exam's scope.

  site with a filterable, chapter-sectioned character table.
